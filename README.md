# 🌿 Dhatuposhana

### Exploring Ayurvedic Physiology Through Interactive Digital Visualization

Dhatuposhana is an educational project designed to explore the concept of the **seven Dhatus** in Ayurveda through an interactive web experience. It aims to make traditional Ayurvedic concepts easier to explore through digital visualization and modern web technologies.

## ✨ Overview

In Ayurveda, the seven Dhatus are described as fundamental bodily tissues that support the structure and functioning of the body. Dhatuposhana explores these concepts through a dedicated interface for each Dhatu.

## 🧬 Explore the Seven Dhatus

| Dhatu | Traditional concept |
|---|---|
| **Rasa** | Nourishing fluid |
| **Rakta** | Blood tissue |
| **Mamsa** | Muscle tissue |
| **Meda** | Adipose tissue |
| **Asthi** | Bone tissue |
| **Majja** | Marrow tissue |
| **Shukra** | Reproductive tissue |

*These descriptions summarize traditional Ayurvedic concepts for educational purposes and are not a substitute for modern medical advice.*

## 🚀 Project Goals

- Present Ayurvedic physiology in an engaging digital format.
- Provide a dedicated exploration experience for each of the seven Dhatus.
- Combine traditional knowledge with interactive web-based learning.
- Explore how digital visualization can support anatomy education.

1. Clone the repository:

   ```bash

   ```

2. Open the project folder.

3. Open `index.html` in your browser.

   For the best development experience, you can use the Live Server extension in Visual Studio Code.
